# musical-carnival

musical-carnival is a Claude Code plugin with Russian-language helper skills for people who are learning programming. It helps you understand code, find mistakes in it and keep a clean git history. All answers are given in simple Russian.

## Skills

**explain-code** explains what a piece of code does, block by block, with examples of input and output. Ask "объясни код" or "what does this code do".

**code-review** checks code for bugs, edge cases, security problems and readability, and shows fixed fragments. Ask "проверь код" or "find errors in this code".

**commit-message** writes a clear git commit message for your current changes. Ask "write a commit message".

**hello** replies with a short, friendly greeting in Russian.

## Installation

Add the plugin from the Claude plugin directory, or install it in Claude Code from this GitHub repository. No extra setup, API keys or external services are required. The plugin does not collect or send any data.
