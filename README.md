# musical-carnival

musical-carnival is a small Claude Code plugin that adds a friendly greeting skill. When you ask Claude to say hello or greet you, the hello skill replies with a short, warm greeting in Russian.

## Installation

Add the plugin from the Claude plugin directory, or install it in Claude Code from this GitHub repository. No extra setup, API keys or external services are required.

## Usage

After installing, ask Claude something like "say hello" or "greet me". Claude will use the hello skill automatically.
