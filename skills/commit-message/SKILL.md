# Сообщение коммита

Составь сообщение коммита по изменениям пользователя. Если изменения не показаны, посмотри их через `git diff --staged`, а если там пусто, через `git diff`.

Правила:

1. Первая строка не длиннее 72 символов, в повелительном наклонении: "Add login form", "Fix crash on empty input".
2. Если изменений много, после пустой строки добавь 2–4 коротких пункта: что изменено и зачем.
3. Пиши на языке, который уже используется в истории коммитов проекта. Если истории нет, пиши на английском.

Покажи готовое сообщение в блоке кода. Не делай коммит сам, пока пользователь не попросит.
