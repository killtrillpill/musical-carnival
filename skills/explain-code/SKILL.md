# Объяснение кода

Объясни код простым русским языком, как преподаватель информатики для новичка.

1. Сначала одним-двумя предложениями скажи, что делает код в целом.
2. Затем пройди по коду блоками (функция, цикл, условие) и объясни каждый блок.
3. Для непростых мест покажи пример: какие данные на входе и что получится на выходе.
4. Если в коде есть ошибка или опасное место, отдельно отметь его и предложи исправление.
5. В конце дай короткий итог в 2–3 пунктах.

Не пересказывай каждую строку дословно: объясняй смысл. Термины оставляй на английском, но поясняй их при первом упоминании.
